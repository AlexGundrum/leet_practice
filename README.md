# LeetCode Practice Environment

TL;DR: This repository contains scripts to fetch, parse, and enrich LeetCode algorithmic problems into structured JSON formats, along with a web-based environment (using Pyodide) to practice and run solutions directly in the browser. 

## Features
- **Data Gathering:** Python scripts to batch and process algorithm problems (`enrich_*`, `build_*`).
- **Web Interface:** `index.html` with Pyodide to run Python code client-side without a backend.
- **Testing:** Scripts for local testing and HTML patching.
